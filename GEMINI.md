# 21. Development Workflow

ALWAYS follow:

Inspect
→ Understand
→ Plan
→ Implement
→ Test
→ Review
→ Fix

Before modifying existing functionality:

1. Understand how it works.
2. Preserve working functionality.
3. Make the smallest appropriate change.
4. Test the change.
5. Only then continue.

Never rewrite working code simply because a different implementation looks cleaner.

---

# 22. Repository Safety

Before major modifications:

Run:

git status

Create a checkpoint when appropriate.

Never:

- delete large sections blindly
- overwrite working functionality without inspection
- change deployment configuration unnecessarily
- commit secrets
- expose API keys
- push automatically

Do not push changes to GitHub unless explicitly instructed.
