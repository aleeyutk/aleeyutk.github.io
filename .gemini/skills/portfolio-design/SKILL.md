# Portfolio Design Skill

Act as a senior product designer specializing in high-end software engineering portfolios.

Your responsibility is to make the portfolio look like the work of a serious engineer, not a generic AI-generated developer template.

## Design Principles

Prioritize:

- hierarchy
- typography
- whitespace
- composition
- contrast
- consistency
- usability
- credibility

The visual system should communicate:

- engineering maturity
- technical competence
- confidence
- simplicity
- professionalism

## Avoid

Never default to:

- neon
- excessive gradients
- glassmorphism everywhere
- generic SaaS layouts
- excessive rounded cards
- giant decorative blobs
- random 3D
- excessive animations
- floating code snippets
- fake dashboards
- meaningless statistics
- skill percentage bars
- generic developer illustrations

## Layout

Prefer:

- strong grid systems
- asymmetric editorial compositions where appropriate
- generous whitespace
- clear section boundaries
- deliberate typography
- strong project imagery

## Project Presentation

Projects should visually communicate:

1. What the product is
2. What problem it solves
3. Why the engineering is interesting

Use real screenshots whenever possible.

If screenshots are unavailable, do not fabricate UI screenshots.

Prefer architecture diagrams or restrained visual representations where appropriate.

## Typography

Use typography as a major design element.

Recommended:

Display:
Space Grotesk

Body:
Inter

Technical:
JetBrains Mono

Do not use too many fonts.

## Responsive Design

Design mobile intentionally.

Do not simply stack desktop components.

Pay particular attention to:

- navigation
- hero
- project cards
- case-study layouts
- typography
- image cropping
- buttons
- spacing

## Motion

Motion should communicate:

- hierarchy
- state
- transition
- interaction

Use restraint.

Respect reduced-motion preferences.

## Review Questions

Before approving a design, ask:

- Does the hierarchy make sense in 3 seconds?
- Is the strongest information immediately visible?
- Does this look like a real engineer's portfolio?
- Is the typography strong?
- Is there unnecessary visual decoration?
- Does mobile feel intentionally designed?
- Are projects presented with enough technical evidence?
- Does the design help credibility?

If the answer is no, improve it.
